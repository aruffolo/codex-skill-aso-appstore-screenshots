# Current delivery requirements

Load before choosing target sizes and again at final export. The original size table is historical guidance, not a complete current platform contract. Delegate verification of the current [Apple screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) through [research.md](research.md); keep the check date and applicable sizes in the campaign report/state. Reuse a verification from the current campaign when it is still applicable.

As checked on 2026-10-20, Apple lists a required medium Dynamic Island iPhone screenshot (1179×2556 or 1206×2622 portrait), and a required 13-inch screenshot set for iPad-supporting apps. The upstream composer's 1290×2796 output is accepted in a large iPhone group; do not claim it covers every required slot. Apple allows 1–10 JPEG/JPG/PNG images per device size and prohibits alpha/transparency. Verify these rules again for a new campaign rather than assuming this dated note remains current.

Lock supported platforms, orientation, required slots, and export dimensions before generation. Preserve the original creative design while producing each needed target; crop proportionally and resize without stretching. Inspect every target separately so cropping does not remove copy or the feature being demonstrated. An iPhone-framed scaffold is not automatically a suitable iPad composition: for iPad delivery, obtain actual iPad captures and agree an explicit layout extension rather than stretching or relabelling the iPhone output. Surface that missing capability before promising a complete iPad set.

Final review must check approved copy and order, consistent device/type/background, readable thumbnail presentation, unclipped text and relevant UI, exact dimensions, no alpha, and real source captures matching the depicted features. Inspect outputs against the [App Review accurate-metadata requirements](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata), including featured paid functionality. Keep only approved target-specific images in `screenshots/final/`, record which upload slot each fits, and create the showcase after every selected final is approved.
